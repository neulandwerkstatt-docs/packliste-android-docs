Daten und Nutzung

Quiravel erhebt, überträgt und speichert keine personenbezogenen Daten auf Servern. Die App benötigt keine Internetverbindung und verwendet kein Tracking, keine Analyse, keine Werbung und kein Konto.

Alle Daten (Vorlagen, Reisen, Packlisten und Einstellungen) werden ausschließlich lokal auf dem Gerät gespeichert. Durch Deinstallation der App oder Löschen der App-Daten werden diese Daten entfernt. Die automatische Android-Datensicherung (Cloud-Backup) ist für die App deaktiviert; Daten verlassen das Gerät nur über einen Export.

Ein Export wird nur auf ausdrückliche Aktion des Nutzers erstellt. Die Datei wird im Ordner Dokumente/Quiravel auf dem Gerät gespeichert oder über das Android-Teilen-Menü weitergegeben, zum Beispiel an einen Cloud-Speicher oder eine Nachricht. Die Sicherungsdatei ist nicht verschlüsselt. Was danach mit der Datei geschieht, liegt beim Nutzer.

Diese Webseite

Diese Datenschutzseite wird über GitHub Pages bereitgestellt. Beim Aufruf kann GitHub technische Daten wie die IP-Adresse verarbeiten. Die App selbst ruft die Seite nicht ab.

Berechtigungen

Speicherzugriff wird nur auf Android 10 oder älteren Versionen angefragt, wenn du eine Sicherung direkt auf dem Gerät speicherst. Die Berechtigung für Benachrichtigungen (Android 13 und neuer) wird nur abgefragt, wenn du eine Erinnerung aktivierst. Die Erinnerungen werden lokal auf dem Gerät geplant; es werden keine Daten übertragen.

Data and app usage

Quiravel does not collect, transmit, or store personal data on servers. The app does not require an internet connection and uses no tracking, analytics, advertising, or account.

All data (templates, trips, packing lists and settings) is stored only on the device. Uninstalling the app or deleting its app data removes that data. Android's automatic cloud backup is disabled for the app; data leaves the device only through an export.

An export is created only at the user's explicit request. The file is saved in the Documents/Quiravel folder on the device or shared through Android's share menu, for example to a cloud drive or a message. The backup file is not encrypted. What happens to the file afterwards is up to the user.

This website

This privacy page is hosted on GitHub Pages. When you open it, GitHub may process technical data such as your IP address. The app itself does not load this page.

Permissions

Storage access is requested only on Android 10 or earlier, when you save a backup directly on the device. The notification permission (Android 13 and later) is requested only when you turn on a reminder. Reminders are scheduled locally on the device; no data is transmitted.
